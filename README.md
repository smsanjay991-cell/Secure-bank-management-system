# Secure Bank Management System

## 📌 Project Overview
Secure Bank Management System is a Java console-based application that allows users to perform basic banking operations securely. The project demonstrates object-oriented programming concepts, exception handling, and Java collections.

## 🚀 Features
- Create a new bank account
- Deposit money
- Withdraw money
- Check account balance
- Custom exception handling
- Menu-driven console application

## 🛠️ Technologies Used
- Java
- Java Collections (HashMap)
- Exception Handling
- OOP Concepts
